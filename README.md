# ResumeForge — Free Resume Builder

## Run on your computer

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. In the terminal run `npm install` then `npm run dev`.
4. Open the localhost URL shown in the terminal.

## What works

- Live resume editing and preview
- Classic and modern templates
- Multiple experience and education entries
- Local browser draft saving
- Free PDF export through browser Print > Save as PDF
- Responsive layout

## Not included yet

- Actual AI writing: requires a server-side API and usage limits to avoid exposing an API key and unexpected charges.
- Accounts, cloud storage, ads, or deployed domain.

Never put a private AI API key in frontend code. Before monetization, add a privacy policy, terms, and substantial helpful content; AdSense approval is not guaranteed.
